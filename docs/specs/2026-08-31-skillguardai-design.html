SkillGuardAI

Static security scanner for AI-agent skills & plugins

1 · Purpose

A static security scanner for AI-agent skills and plugins — the SKILL.md + script bundles that Claude Code and similar agents install and run. It answers one question before you trust a skill: is this safe to install?

v1 is a personal hardening tool — point it at your own ~/.claude/skills, ~/.agents/hooks, or an unvetted plugin. It never executes the skill and makes no network calls. Structured to graduate into a publishable CLI later without a rewrite.

Non-goals (v1)

  • No skill execution, ever
  • No network (no CVE lookups, no LLM)
  • Not a fork of NVIDIA/skillspector — shared concept, independent code

2 · Scope

In scope (v1)

  • Scan one skill dir: skillguardai scan <path>
  • Batch scan a folder: skillguardai scan <dir> --all
  • Parse SKILL.md frontmatter (name, description, triggers)
  • Data-driven TOML rule pack across 7 categories
  • 2 structural checks (trigger breadth, executable-script presence)
  • Weighted score 0–100 → verdict band → decision-shaped exit code
  • Terminal (default) + --json output; fail-closed input handling

Deferred to v2 (YAGNI now)

  • LLM semantic stage · OSV.dev/CVE · SARIF
  • MCP-server mode · Python AST + taint tracking
  • Unicode-confusable detection · baseline suppression files

3 · Architecture

Crate layout

skillguardai/
  Cargo.toml
  rules/default.toml        # rule pack — DATA, not code
  src/
    main.rs / cli.rs        # scan; --all; --json
    walker.rs               # safe walk + size caps (fail-closed)
    skill.rs                # parse SKILL.md; locate scripts
    rules.rs                # load/represent the TOML rule pack
    engine.rs               # apply rules + structural checks -> findings
    findings.rs             # Finding / Severity / Category
    score.rs                # score -> verdict -> exit code (pure)
    report.rs               # terminal + JSON (pure)
  tests/fixtures/           # clean + malicious sample skills

Two-layer detection

Layer 1 — Rule pack (TOML, data). Add a detection = edit TOML, no recompile:

[[rule]]
id          = "exfil-curl-pipe-sh"
category    = "data-exfiltration"
severity    = "critical"
description = "Pipes a downloaded script straight into a shell"
pattern     = 'curl[^\n]*\|\s*(ba)?sh'

Layer 2 — Structural checks (Rust). Trigger breadth (*/empty/.* → excessive-trigger finding) and executable-script presence (sets the score multiplier + a note).

Seed categories (~20–25 rules)

CategoryExample detections
prompt-injection"ignore previous instructions", role-override
data-exfiltrationcurl … | sh, POST file contents to remote
credential-accessreads of ~/.ssh/id_*, .env, ~/.aws, keychains
dangerous-execeval, exec, os.system, backtick shell-out
supply-chainnpm/pip install from raw URL or git ref
excessive-triggeroverly broad activation (fed by structural check)
obfuscationlarge base64/hex blobs, base64 -d | sh

4 · Data Flow

scan <dir> [--all] [--json]
   → [walker]  enumerate + caps + skip binaries  --oversize/unreadable--> ERROR (exit 2)
   → [skill]   parse SKILL.md frontmatter; collect scripts
   → [engine]  rule-pack patterns per file + structural checks
   → [score]   Σ weighted severities × script multiplier → 0..100 → band → exit
   → [report]  terminal (default) or JSON

--all runs the flow per subdirectory containing a SKILL.md; the worst verdict drives the process exit code.

6 · Error Handling (fail-closed)

  • Oversized input (file 1 MiB / bundle 20 MiB / 2000 files caps) → error, exit 2. Never treat un-scannable as safe.
  • Unreadable files → error finding, not a silent skip.
  • Malformed frontmatter → warning finding, keep scanning contents.
  • Missing SKILL.md → still scan scripts, note absence.
  • Binary files → skipped by walker.

7 · Testing (TDD)

  • tests/fixtures/: one clean skill (LOW, exit 0) + one malicious per category (HIGH/CRIT, exit 1).
  • Write fixture + expected verdict first, then the rule/check that passes it.
  • Pure modules (score, report) unit-tested; integration test runs the real binary against fixtures.
